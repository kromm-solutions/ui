## Usage

```tsx showLineNumbers
import { CodeBlock } from "@/components/ui/code-block";
```

```tsx showLineNumbers
<CodeBlock code={source} filename="submit-button.tsx" language="tsx" />
```

`CodeBlock` highlights its input on the server with [shiki](https://shiki.style) using the
`github-light` / `github-dark` pair, so it must be rendered in a server component. The
highlighted output carries `--shiki-light` / `--shiki-dark` on every token, which is what the
styles above consume.

## Composition

```text
CodeBlock
├── CodeBlockCopy        (header action, or floating when there is no filename)
└── CodeBlockCollapse    (only when `collapsible`)
```

`CodeBlockCopy` and `CodeBlockCollapse` are exported too, for building your own chrome.

## API

| Prop              | Type      | Default   | Description                                                                 |
| ----------------- | --------- | --------- | --------------------------------------------------------------------------- |
| `code`            | `string`  | —         | Source to highlight.                                                        |
| `language`        | `string`  | `"tsx"`   | Shiki language id. Unknown ids fall back to plain text instead of throwing. |
| `filename`        | `string`  | —         | Renders the header and names the scroll region.                             |
| `lineNumbers`     | `boolean` | `false`   | Numbered gutter.                                                            |
| `collapsible`     | `boolean` | `false`   | Clamp the code to `collapsedHeight` with an expand toggle.                  |
| `collapsedHeight` | `string`  | `"16rem"` | Visible height while collapsed.                                             |
| `className`       | `string`  | —         | Applied to the outer surface.                                               |

## Accessibility

- The highlighted block is a focusable `role="region"` with an accessible name, so a keyboard
  user can scroll long lines without a mouse.
- That focus stop draws a `2px` ring inset inside the surface, so the rounded container cannot
  clip it and the indicator stays visible.
- The copy button has a name in both states (`Copy code` / `Copied`) and reports the result
  through an `aria-live` status region.
- The copy button cross-fades between its two icons; under `prefers-reduced-motion` the swap is
  instant, and the state is never carried by motion alone (the name and the status region
  change too).
- If the clipboard is blocked by the browser, the button stays on `Copy code` instead of
  claiming a copy that did not happen.
- Line numbers are decorative: the gutter is generated by CSS, so it is never read twice.
