title: Installation
description: How to install components from the kromm registry in your project.
---

## Prerequisites

Your project must already use the shadcn setup with Tailwind CSS. If not, run:

```bash
npx shadcn@latest init
```

## 1. Choose your base and style

Every component ships on three headless bases — `base` (Base UI), `aria`
(React Aria) and `radix` (Radix) — and eight visual styles (`vega`, `nova`,
`maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`). The distribution URL of an
item encodes both axes:

```
/r/styles/{base}-{style}/{name}.json
```

For example, the `signature-pad` in the Radix base with the Vega style:

```
/r/styles/radix-vega/signature-pad.json
```

## 2. Register the namespace

Add the `@kromm` namespace to the `registries` field of your `components.json`
once, pointing at your preferred base and style:

```bash
npx shadcn@latest registry add @kromm=https://ui.kromm.io/r/styles/radix-vega/{name}.json
```

Then add any item:

```bash
npx shadcn@latest add @kromm/signature-pad
```

To switch bases or styles, register another alias, for example
`@kromm-base=https://ui.kromm.io/r/styles/base-vega/{name}.json`.

## 3. Browse the registry

```bash
npx shadcn@latest list @kromm
npx shadcn@latest search @kromm --query signature

```

## Install by URL

Every item is also served as a plain JSON endpoint, no namespace needed:

```bash
npx shadcn@latest add https://ui.kromm.io/r/styles/radix-vega/signature-pad.json
```

## Themes and fonts

Themes live under `/r/themes/<theme>.json` and fonts under
`/r/fonts/font-<name>.json` / `/r/fonts/font-heading-<name>.json`:

```bash
npx shadcn@latest add https://ui.kromm.io/r/themes/emerald.json
npx shadcn@latest add https://ui.kromm.io/r/fonts/font-inter.json
```

## Publishing to this registry

The registry is generated, never hand-edited:

1. Author the component under `registry-kromm-ui/bases/<base>/kromm-ui/<name>/`,
   plus its examples under `registry-kromm-ui/bases/<base>/examples/<name>/`
   with a `meta.json`.
2. Declare the item in `registry-kromm-ui/bases/<base>/kromm-ui/registry.ts`.
3. Rebuild the pipeline:

```bash
pnpm registry:all
```

That runs `build-metadata` → `build-registry` → `verify-registry` and
regenerates `public/r/`. See [Contributing](/docs/contributing) for the full
conventions.
